# Задание 5 · sre-observability

**Дата:** 2026-10-21. **Пилот:** Antigravity. **Архитектор:** Conductor (`ik`).
**Полномочия:** авторизовано Кондуктором в рамках пакетной модели поставки курса (батч 5 из 5: мультиязычная синхронизация, дизайн-акцент навигации и релизная полировка).

## Хочу

Завершить пятый, финальный пакет курса:
- Реализовать мультиязычную целостность и связность всех страниц курса: синхронизировать языковые заглушки (stub-card) на английском (`en/`), украинском (`uk/`) и немецком (`de/`) языках для всех 15 глав, словаря и навигатора (всего 73 страницы). Все карточки заглушек ведут на актуальные русские страницы-первоисточники с точными названиями глав, корректным переводом служебных элементов и нулевым количеством битых ссылок.
- Применить согласованное с Кондуктором дизайн-улучшение липкого меню навигации: акцентный янтарный вертикальный маркер 3px (`border-left: 3px solid var(--term-accent)`) для активных разделов меню (главы 01-15), инструментов-спутников в `.nav-extra` (`glossary.html`, `navigator.html`) и пунктов внутристраничного содержания (`.toc-list a.active`), визуально рифмующийся с блоком «Главная мысль» (`.box.key`). Улучшение вносится через росток (`seed/swa/assets/style.css`) и синхронизируется в репозиторий изолированным коммитом по правилу §1 AGENTS.md.
- Зафиксировать паттерн Active Tool Promotion в `.nav-extra` на всех иноязычных версиях страниц-спутников (`glossary.html` и `navigator.html`).
- Провести предрелизную верификацию: поднять номер версии в `site.conf`, пересобрать навигацию (`tools/build-nav.py`), метаданные (`tools/build-meta.py`), поисковые индексы (`tools/build-search.py`), обеспечить полное прохождение `./check.sh` со статусом ЗЕЛЁНОЕ (9/9) и составить отчёт сдачи смены `lessons/record-5.md`.

## Предикаты

1. **Мультиязычная целостность и верстка 73 страниц подтверждены машиной.** Все 73 страницы сайта (`ru/`, `en/`, `uk/`, `de/`) полностью синхронизированы по структуре; навигация содержит правильные названия глав и инструментов; карточки-заглушки в `en/`, `uk/`, `de/` не содержат устаревших плейсхолдеров и корректно ссылаются на русский оригинал с точным языковым наименованием (в `uk/` используется каноническая форма «руською мовою»); на страницах-спутниках соблюден паттерн Active Tool Promotion; проверка 390px мобильного экрана и 860px высоты липкого сайдбара проходит с 0 брака. **Чем проверяется:** машиной - `python3 tools/build-meta.py --check && python3 tools/build-nav.py --check && node tools/check-pages.mjs en/navigator.html uk/navigator.html de/navigator.html en/glossary.html uk/glossary.html de/glossary.html` возвращают 0; тест мобильного вьюпорта и липкой панели в `./check.sh` дает 0 в браке из 73 страниц.

2. **Дизайн-акцент активных элементов навигации реализован через росток.** В общих стилях платформы через росток (`seed/swa/assets/style.css`) реализован 3px вертикальный янтарный маркер `border-left: 3px solid var(--term-accent)` для `nav.contents li > a[aria-current="page"]`, `nav.contents .nav-extra a[aria-current="page"]` и `.toc-list a.active`; изменение внесено в репозиторий курса изолированным коммитом `chore(engine): ...` с подтвержденным отсутствием конфликтов и визуальной деградации. **Чем проверяется:** машиной - `grep -F 'border-left: 3px solid var(--term-accent)' assets/style.css` находит определения для пунктов меню и `.nav-extra`; `git log -1 --grep="chore(engine)"` фиксирует изолированный коммит синхронизации из ростка.

3. **Релизная готовность и целостность подтверждены чекером 9/9 ЗЕЛЁНОЕ.** Номер версии `version` в `site.conf` зафиксирован; поисковый индекс, метаданные и навигация актуализированы генераторами; дерево `git status` чистое; полный `./check.sh` возвращает 0 с итоговым вердиктом ЗЕЛЁНОЕ по всем 9 блокам проверок. **Чем проверяется:** машиной - `./check.sh` возвращает код 0 со строкой ЗЕЛЁНОЕ (9/9); `git diff --exit-code` подтверждает чистоту рабочего дерева перед сдачей смены.
